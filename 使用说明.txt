======================================================================
        Antigravity 简体中文独立便携汉化包（无损动态注入版）
======================================================================

一、汉化包简介与核心特点
----------------------------------------------------------------------
1. 独立便携、零外部依赖
   整个文件夹自带全部运行脚本与词库，不依赖第三方 npm 包，可直接
   打包或复制到任意 Windows 10 / Windows 11 电脑上使用。

2. 无损绿色、不篡改官方文件
   本汉化包不会修改 Antigravity 官方安装目录中的 app.asar、
   language_server.exe 等任何原生程序文件，彻底避免破坏客户端签名
   或因官方更新导致补丁失效。

3. 随官方版本自动兼容、保留英文原版入口
   通过本地 Chrome DevTools Protocol (CDP) 在界面渲染层动态注入
   汉化引擎与词库（内置 3,333 条高覆盖词条与正则规则）。
   Antigravity 自动更新版本后通常可继续正常使用；同时保留桌面原有
   的英文版「Antigravity」快捷方式互不干扰。

4. 保留专业标识与代码可读性
   所有 AI 模型名称、代码块、文件路径、命令参数与 URL 均保持英文
   原样，仅翻译菜单、设置面板、按钮、提示文案与动态耗时/权限提示。


二、运行环境要求
----------------------------------------------------------------------
1. 操作系统：Windows 10 / Windows 11
2. 客户端  ：已安装 Antigravity 桌面客户端
3. 运行时  ：已安装 Node.js 22 或更高版本（推荐官方 LTS 长期支持版）
   * 下载地址：https://nodejs.org/
   * 如目标电脑未安装 Node.js，请先前往上述官网下载安装包一键安装
     后再使用本汉化包。


三、安装与使用步骤（含复制到其他电脑）
----------------------------------------------------------------------
第 1 步：放置汉化包文件夹
   将整个「Antigravity中文包」文件夹复制到目标电脑的固定位置
   （例如桌面、文档目录或 D:\Tools\Antigravity中文包 等不易误删的
   文件夹中）。
   * 注意：生成桌面快捷方式后，请勿随意移动或删除本文件夹；如果日
     后更换了文件夹存放路径，重新执行第 3 步即可自动更新指向。

第 2 步：确认基础环境
   确保目标电脑已经安装 Antigravity 客户端以及 Node.js 22+。

第 3 步：一键创建桌面中文快捷方式
   双击运行本文件夹内的「创建桌面中文快捷方式.bat」。
   - 脚本会自动检测系统中的 Node.js 版本和 Antigravity.exe 路径；
   - 自动适配当前用户真实的桌面目录（包括 OneDrive 重定向桌面）；
   - 在桌面生成「Antigravity 中文版」快捷方式（不会影响原有的英文版
     「Antigravity」快捷方式）。

第 4 步：启动使用
   - 双击桌面「Antigravity 中文版」：进入简体中文界面（无黑框静默启动）。
   - 双击桌面原「Antigravity」：进入英文原版界面。


四、快捷键、自定义词典热更新与版本更新说明
----------------------------------------------------------------------
1. 一键中英切换快捷键：Ctrl + Alt + L
   在 Antigravity 窗口处于聚焦状态时，按下 Ctrl + Alt + L 即可立即在
   「简体中文」与「英文原版」之间切换，无需重启客户端。

2. 自定义词典热更新（dict.custom.json）
   如果你希望修改某些翻译用词，或官方未来更新后出现了个别新菜单文
   案，只需用记事本或代码编辑器打开同目录下的 dict.custom.json，按
   JSON 键值对格式填入即可，例如：
   {
     "Some New English Label": "你的自定义中文译文"
   }
   保存文件后，启动器会在后台自动检测到变动并在数秒内热更新到已
   打开的窗口中，无需重启 Antigravity。
   * 提示：dict.custom.json 的优先级高于内置主词典 dict.zh-CN.json；
     后续若获取新版汉化包覆盖更新时，注意备份保留自己的
     dict.custom.json 即可延续个性化翻译。

3. 随官方客户端更新
   当 Antigravity 官方客户端自动升级到新版本后，直接双击桌面
   「Antigravity 中文版」照常启动即可继续享用汉化，无需重新打补丁。


五、包内文件列表（共 8 个文件）
----------------------------------------------------------------------
1. launcher.mjs                核心启动器与 CDP 监听守护进程（含热重载）
2. injector.js                 动态界面注入翻译引擎（v2 版）
3. dict.zh-CN.json             内置简体中文主词典（3,333 条词条）
4. dict.custom.json            用户自定义覆盖词典（默认为空 {}）
5. launch-silent.vbs           Windows 无黑框静默启动脚本
6. install-shortcut.ps1        桌面快捷方式安装与环境检测 PowerShell 脚本
7. 创建桌面中文快捷方式.bat     一键调用安装脚本的批处理入口
8. 使用说明.txt                本使用说明文档

* 首次运行后，本目录下会自动生成一个 launcher.log 运行日志文件，属于
  正常现象，便于排查问题。


六、常见问题排查与无残留卸载
----------------------------------------------------------------------
Q1：启动时提示“检测到 Antigravity 正在英文模式下运行”或页面未汉化？
   答：如果之前已经用英文版启动了 Antigravity，或系统托盘中仍有残留
       的 Antigravity 后台进程，中文模式需要的本地调试端口不会生效。
       请在弹窗中点击“是”让启动器自动重启切换为中文；若仍未生效，
       先右键退出系统托盘中的 Antigravity（或在任务管理器结束所有
       Antigravity.exe 进程），再重新双击「Antigravity 中文版」。

Q2：运行快捷方式提示缺少 Node.js 或版本过低？
   答：本汉化包使用 Node.js 22+ 原生内置的 fetch 与 WebSocket 能力。
       请前往 https://nodejs.org/ 安装最新的 Node.js 22 或更高版本
       （LTS）即可，默认安装路径与系统 PATH 均可自动识别。

Q3：提示“未找到 Antigravity.exe”？
   答：启动器会自动查找默认安装路径、桌面以及开始菜单中的快捷方式。
       如果你的客户端安装在自定义特殊路径，可以在 Windows 系统环境
       变量中新增变量名 ANTIGRAVITY_EXE，变量值设为 Antigravity.exe
       的完整路径。

Q4：默认调试端口 19222 与其他软件冲突怎么办？
   答：可在 Windows 环境变量中设置 ANTIGRAVITY_ZH_PORT 为其他未被占
       用的端口号（例如 19333），启动器会自动改用新端口。

Q5：如何查看启动与注入诊断信息？
   答：使用记事本打开本目录下的 launcher.log，即可查看 Node.js 检
       测、客户端启动、词典条数加载以及窗口连接状态记录。

Q6：如何彻底卸载（零残留）？
   答：由于本汉化包未改动 Antigravity 安装目录与注册表，卸载只需两步：
       1) 删除桌面上的「Antigravity 中文版」快捷方式；
       2) 删除整个「Antigravity中文包」文件夹。
